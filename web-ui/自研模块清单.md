# 自研模块清单（低代码部分）

本文件说明本项目里**本轮自研的低代码相关代码**落在哪里、各自负责什么，以及与原有代码的边界。

整理日期：2026-11-06

---

## 一、目录位置

| 目录 | 内容 | 是否进部署包 |
|---|---|---|
| `frontend/lowcode/` | 4 个页面 + `renderer.js` + `config-schema.js` | 是 |
| `frontend/lowcode/_proto/` | 两个弃用原型（原生表格版、amis 版） | **否**，`CopyFrontend` 已排除 |
| `backend/LowCode/` | `FlowConfig.cs`、`FlowTemplateService.cs`、`NodeTypeController.cs` | 编译进 exe |

页面访问地址随之变为 `http://localhost:8888/lowcode/xxx.html`。

## 二、前端（`frontend/lowcode/`）

| 文件 | 职责 |
|---|---|
| `workflow-designer.html` | 主线编排设计器：四栏（图标条 / 环节库 / 画布 / 属性面板）+ 模板下拉 + 「定义」「参数」入口，约 51 KB |
| `node-types-editor.html` | 环节定义编辑页：左分组树 + 右表单 + JSON 原文弹窗，保存时双写源码，约 32 KB |
| `system-config.html` | 系统参数页：11 个页签，覆盖 PLC / 机床 / 料架 / 夹爪 / eman 等，约 26 KB |
| `node-demo.html` | 渲染器验证页，仅用于开发自检 |
| `renderer.js` | **元数据 → 表单** 渲染器，234 行原生 JS，零依赖。类型注册表 5 种：`number` / `text` / `enum` / `switch` / `path` |
| `config-schema.js` | 参数页结构定义，挂到 `window.CONFIG_SCHEMA`。用 `.js` 不用 `.json`，避免 `/config.json` 被直接下载（内含数据库密码） |

## 三、后端（`backend/LowCode/`）

| 文件 | 职责 |
|---|---|
| `FlowConfig.cs` | 流程模型 + `Normalize()` 归一化 + `MergeKnownSteps()` 自动补步骤 + 手写序列化（带缩进，人能直接改） |
| `FlowTemplateService.cs` | 多模板：列表 / 新建 / 切换 / 改名 / 删除，含运行中拒绝、非法名拒绝、空模板强制停用+仿真 |
| `NodeTypeController.cs` | 环节定义读写，保存时校验 JSON + 备份 `.bak` + `FindSourcePath()` 双写源码 |

三个配置文件是真源，代码只负责读写：

| 文件 | 位置 |
|---|---|
| `node-types.json` | `backend/`（构建时复制到输出目录） |
| `flows/*.json` | 输出目录 `flows/`，一个模板一个文件 |
| `config.json` | 输出目录根，设备参数 |

## 四、与原项目代码的边界

**新增**（本清单列举的 9 个文件）与**改动**要分清：

| 类别 | 文件 |
|---|---|
| 新增 | 上表 9 个 |
| 改动 | `Router.cs`（加 8 条低代码路由）、`AppState.cs`（路径族）、`WorkflowService.cs`（仿真/超时/停止）、`ConfigService.cs`（`SaveConfigRaw`）、`MachineMonitor.csproj`（`CopyFrontend` + `_proto` 排除）、`frontend/index.html`（未加菜单入口） |

## 五、第三方依赖

| 库 | 版本 | 协议 | 用在哪 |
|---|---|---|---|
| SortableJS | 1.15.6 | MIT | 仅 `workflow-designer.html` 拖拽节点 |

`_proto/workflow-amis.html` 引用了百度 **amis 6.4.0（Apache-2.0）**，该页已弃用且**不进部署包**，因此分发物中不含 amis。若将来恢复原型投放到现场，须同时附带 Apache-2.0 许可证副本。

## 六、构建与部署注意

1. 改前端页面后必须 `dotnet build` —— `CopyFrontend` 是 `AfterTargets="Build"`，不编译不生效。
2. `_proto/` 与 `*.bak*` 已在 csproj 里排除，不会进 `bin`。
3. 后端新增 `.cs` 无需改 csproj（SDK 风格自动 glob）。
4. 移动目录后**不必**改 `HomeController`：它按 `AppState.ExeDir` 相对路径服务静态文件，子目录自动支持。
