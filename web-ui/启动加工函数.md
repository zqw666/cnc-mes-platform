
## 3. 已采用方案：通过 PLC 发送启动加工命令

`load_machine` 对西门子机床（`type=siemense`）**放满 4 件后**才启动加工：前 3 件只写入工位表（待加工，`workpiece_status=0`），第 4 件放满后执行 `HandleUploadProgram`（合并上传 + 启动），启动成功后该机床所有有件工位置 `workpiece_status=1`。启动经 PLC 发送命令（复用机器人任务模式 `ExecuteTask`）：

```
① Plc.WriteDM(任务号DM, 启动任务号)
② Plc.WriteWR(开始信号, 1)
③ 轮询等待完成信号 == 1
```

实现（`Program.cs` `HandleUploadProgram`）：
- 主流程步骤 7：放件后查空工位，未满则记录待加工并直接结束（不启动）；满 4 件才进入上传+启动
- 主流程步骤 9：启动成功后 `UpdateMacWorkPosStatusAll(macnum,1)` 将该机床所有有件工位置加工中，并批量更新料架（`GetMacFilledWorkpieces`）
- 配置 `plc.signals.machine.startTaskNo`（当前模拟占位 300；0/未配置则回退机床通讯启动 `MacStartProcessSafe`）
- 已配置 → `ExecuteTask(startTaskNo)`：写 DM100=300 → 置 104.00=1 → 等 205.00=1 → 成功后工位置"加工中"
- DM/开始/完成信号复用 `plc.signals.robot` 的 `taskNumber/taskStart/taskDone`（模拟占位 D100/104.00/205.00）

## 4. 模拟器现状

`plc-simulator/load_machine_sim.py` 已实现 PLC 启动加工模拟（`plc_start_machine`：写 DM100=任务号 → 置开始信号 → 等完成信号），任务号默认 300、可被 `config.json` 的 `plc.signals.machine.startTaskNo` 覆盖；`--no-shuttle --robot-piece <工件名>` 可完整模拟"西门子无随行台：机器人工件 → 机床空工位 → 上传NC → PLC启动 → 加工中"。
